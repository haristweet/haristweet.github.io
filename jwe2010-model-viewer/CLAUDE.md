# Jリーグウイニングイレブン2010 クラブチャンピオンシップ モデルビューア — 作業メモ

PS2『Jリーグウイニングイレブン2010 クラブチャンピオンシップ』（SLPM-55262）の選手を、正しい顔と髪でブラウザに出す。公開は `index.html` 1枚。
進め方の決まりは `../tobal1-model-viewer/CLAUDE.md`、教訓は `../CLAUDE.md` と同じ（返事は日本語、始める前に許可、絵を見ずに言わない）。
形と絵の読み方は `../we2012-model-viewer/` と同じ（`src/we12.js`・`wgl.js`・`raster.js`・`png.mjs`・`shot.mjs` はそこから写した。直すときは両方）。
ユーザーの目当ては「ベガルタ仙台の選手がきちんと表示できること」。WE2012 には J リーグが無いのでこちらに移った。

## いまの状態

- v0.1.0（2026-10-12）: ディスク＋ステートセーブ（.p2s）を開く → 選手を名前で選ぶ → 顔と髪。偽のディスク（見本 60 個）と本物のセーブで、PC とスマホの幅でたどった
- 次の候補: 髪の色（記録のどこか）、チームごとの分け方（名簿の表）、ディスクの中の選手の表（混ぜてあるらしい）、目が閉じて見える（WE2012 と同じ）

## ページ（`index.html`、版は `src/app.js` の VERSION、履歴は CHANGELOG.md）

```
cd jwe2010-model-viewer/src
sh check.sh          # 組み立て（assemble.py が head.html と fzstd.js・we12.js・p2s.js・wgl.js・app.js を連結）→ 単体試験 → ../index.html
node mkfake.mjs      # data/ の見本から偽のディスク out/fake_0_TEXT.AFS・out/fake.iso
node browser.mjs     # Playwright。何も無し → セーブ（data/sekiguchi.p2s）→ ディスク → 名前で探す → 次 → 番号 → PNG
sh shots.sh          # 絵で確かめる一覧 out/shots/sendai.png・others.png（前回は out/prev/）
```
- `fzstd.js` は fzstd 0.1.1（MIT、ライセンスは中に）。.p2s の中身が zstd（zip の方式 93）なので。古い PCSX2 の deflate（方式 8）も読む

## 分かったこと

- 【確定・数字】AFS・圧縮・入れもの・形・絵の読み方は WE2012 と同じ。頭が 0x10600 と 0x10E00 の 2 種類あり、どちらも +32 から zlib
- 【確定・数字】セーブのメモリ（eeMemory.bin）に選手の表。1 人 0x7C バイト、関口のセーブでは 0x194B43C から 4,609 人（先頭は林 卓人、関口は 8 人目）。
  0＝名前（UTF-16、16 字）、0x20＝背中の名前（ASCII）、0x30＝呼び名の番号（関口 0x7BA、梁 0x7B9）、0x36〜＝能力値（画面の 68,42,65,… と一致。上のビットに印）。
  ページは「名前と背中の名前として読める記録がいちばん長く続く所」を表とする（`jwFindTable`）
- 【確定・数字】顔＝0x5C の 16 ビットの下 12 ビット＋921、髪＝0x64 の 16 ビットの上 11 ビット＋6614。
  メモリに読み込まれていた顔 6 つ・髪 5 つ（形と絵の一部をディスクの全ファイルと照合して番号を出した）が、関口 #3377/#7188・菅井 #3381/#7192・萬代 #3382/#7193 と一致。
  足す数は差から決めただけで、ゲームの中の計算は見ていない。0x5C の上 4 ビットは何かの印（多くは 1）
- 【絵で確認】表の先頭 30 人の顔は全部 MMT・髪は全部 MTT。関口・梁・林・菅井・フェルナンジーニョ・レイナルド・エリゼウ・朴 柱成を描いて、髪が頭に合う
- 【未解決】髪の色: ファイルの色表は選手ごとに違うが、関口の髪の色表は灰色（ゲームの画面では茶色）。メモリの色表もファイルと同じなので、描くときに色を掛けている【推測】。記録のどの欄かは未確認
- 【未解決】ディスクの中の選手の表: ほどける所（0_TEXT・J_TEXT・OVER・本体）を全部探しても名前・能力値・背中の名前が見つからない。混ぜてある【推測】
- 【数字】0_TEXT #656〜#661 は実況の呼び名の一覧（6 か国語、#660 が日本語カタカナ。0x30 バイト [番号, 番号, 名前]、5,172 件）
- 【数字】0_TEXT #1238〜#1249 は頭が PES3・PES4・PES5・WE7・WE8・WE9・WE10 など（前の作品のセーブを読むための表？）
