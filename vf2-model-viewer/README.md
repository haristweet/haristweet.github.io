# バーチャファイター2 モデルビューア

PS2『SEGA AGES 2500 Vol.16 バーチャファイター2』のディスクのイメージと、対戦中の PCSX2 のセーブステート（.p2s）を読み込むと、
そのコマでゲームが描いた2人を、そのままの姿勢と色で取り出して回して見られる。ファイルはブラウザの中だけで読む。

ページ: https://haristweet.github.io/vf2-model-viewer/

## できること（v0.14.0）

- 読み込むもの: ディスクのイメージ（.bin/.iso/.cvm）・セーブステート（.p2s）・MAME のロム vf2.zip（なくてもよい）。ページへのドロップでも読める
- 写しのコマの2人と背景（ステージ・空と遠景）を、ゲームと同じ色と明るさで描いて回して見る。写しが無くてもディスクだけでモデルを見られる
- アーケードのロムがあれば、キャラとステージのテクスチャをアーケード（Model 2）の細かさで描く（PS2 版は横が 1/4）
- 技を出す: アーケードのプログラム（i960）をページの中で動かし、技の番号とコマを選んでその姿勢に置き直す。手の形は技の台本どおり。コマ送り・再生・「ランダムに連続」
- 保存: スクショ（背景なしの透過・キャラだけ切り抜き）、動画（MP4／WebM、アニメーション PNG）。背景の色は8種から
