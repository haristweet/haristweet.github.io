Suno スタイル帳これまで作った曲調を探して、Style と Exclude を一発でコピー

Style と Exclude にライブ録音の言葉を足してコピーします（Exclude の live drums live band などは外します）。歌詞欄の最初に [Crowd Cheering]、最後に [Applause] を入れると歓声と拍手が入りやすくなります。インスト曲では歌詞欄が使われないので、Style だけで効かせます。

Style と Exclude に DJ 用エクステンデッド・ミックスの言葉を足してコピーします（リズムだけの長い頭と終わり、フェードアウトなし）。Instrumental はオフにして、歌詞欄は [Intro] [Drums Only] で始め [Outro] [Drums Only] [End] で終えるタグだけに。Duration は Custom 6:30〜7:30。短く終わったら最後から Extend で [Outro] [Drums Only] を足します。
