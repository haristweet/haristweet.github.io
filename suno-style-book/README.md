# Suno スタイル帳 — 中身の管理

公開ページ: https://haristweet.github.io/suno-style-book/

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | ページ（見た目と動き）。版は `const VERSION` の1か所。更新履歴はページ下の `<details>` |
| `data.json` | プロンプト全部（1件＝1つの版） |
| `tools/add_from_md.py` | 決まった形の .md から `data.json` に足す |

## 1件の形（data.json）

| 項目 | 意味 |
|---|---|
| `id` | `s` ＋ 通し番号。新しいほど大きい（「新しく追加した順」に使う） |
| `song` | 作った曲の名前。曲を決めないひな形は `汎用テンプレート` |
| `genre` | 曲調の名前（カードやボタンに出る） |
| `cat` | 分類（ページ上のジャンルのボタン） |
| `group` | まとまりの名前（検索に使う。例：`韓国` `日本・歌謡曲`） |
| `set` | （任意）近いひな形を1枚のカードにまとめるときの名前 |
| `style` / `exclude` | Suno に貼る文 |
| `notes` | メモ（`` `…` `` はコードの見た目になる） |
| `mix` / `mixStatus` | ミックス名と「決定／候補」 |

カードのまとまり方：同じ `song` の版は1枚に、`set` が同じひな形も1枚に、それ以外のひな形は1件1枚。
`group` が「…追加」で終わるもの（ライブ版・EXTEND MIX）は一覧に出さず、チェックボックスから使う。

「歌の言葉」と「年代」は書かなくてよい。Style の中の `japanese` `korean` `mandarin` や `1983` などから、ページが自動で読む。

## 足しかた

1. プロンプトを .md に書く（形は `tools/add_from_md.py` の先頭の説明のとおり）
2. `python3 suno-style-book/tools/add_from_md.py 足すファイル.md --check` で確かめる
   - 長い `[タグ]`（歌われてしまう）、Style と Exclude の食い違い、年・BPM の書き忘れ、重複を知らせる
3. 問題なければ `--check` を外して実行すると、`data.json` に足される
4. `index.html` の `VERSION` を上げ、更新履歴の先頭に1行足す。トップページ（`/index.html`）の件数と版も上げる

## 分類

歌謡曲 / ポップス / ロック／パンク / フォーク / R&B／ソウル / ジャズ／フュージョン / ヒップホップ / ビッグビート / ブレイクコア／DnB / ハウス／ディスコ / テクノ / 80s／シンセ / アンビエント／エレクトロニカ / ワールド / いまの流行 / その他

分類を増やすときは `index.html` の `CATS` と `tools/add_from_md.py` の `CATS` の両方に足す。
