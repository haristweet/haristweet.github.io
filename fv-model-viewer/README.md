# ファイティングバイパーズ モデルビューア

PS2『SEGA AGES 2500 Vol.19 ファイティングバイパーズ』のディスクのイメージ（.chd・.bin など）と、対戦中の PCSX2 のセーブステート（.p2s）を読み込むと、
そのコマでゲームが描いた2人を、そのままの姿勢と色で取り出して回して見られる。テクスチャはディスクに入っているアーケード版の細かさで描く。
ファイルはブラウザの中だけで読む。ゲームのデータはリポジトリに入れない。

ページ: https://haristweet.github.io/fv-model-viewer/　作業メモは [CLAUDE.md](CLAUDE.md)、変更履歴は [CHANGELOG.md](CHANGELOG.md)。
