トバルNo.1 モデルビューア

手元のディスクイメージからキャラクターを取り出して表示します・ 非公式

読み込み元

ファイル

向き

モデルの「背の高さ」がどの軸かはファイルに書かれていません。実物は X 811 / Y 411 / Z 417 で、X が背の高さ（人の縦横比 2:1:1）でした。そのうえで上下をひっくり返した「X を上（逆）」が既定です。人の形にならないときはここを変えてみてください。
メモリの写しから出しているときは「そのまま」です。本物の骨を当てたあとは、ワールドの Y がそのまま背の高さになります。写しを読み込むと自動でこちらに変わります。

キャラクターを見分ける

キャラクターのモデルを順に描いて、小さな絵にして並べます。形と色で誰が誰かを見分けるための道具です。絵を押すと、そのモデルに切り替わります。見出しの「命令」は命令の列として実行できた部品の数で、「推測」が付いているもの（橙色）は読み切れずに形が崩れています。

命令5 で区切られたかたまりを1つずつ描いて並べます。どの区切りが腕・脚・胴・頭なのかを見分けるための道具です。

テクスチャ

キャラクターの体には貼り先（UV）がなく、頂点の色だけで塗られています。テクスチャは顔のパーツ（目・口）や背景・文字に使われていて、体とは別に描かれます。「すべて並べて見る」で見比べられます。

メモリの写し（本物の骨）

VRAM ダンプ（1,048,576バイト）も、ここに入れてください。キャラクターの模様（胸の紋章、ブーツの三角など）はテクスチャで、その絵は VRAM にあります。RAM ダンプには入っていません。両方入れると模様まで出ます。

写しの中にいた人

ディスクのファイルではなく、写しに載っているモデルそのものを出しています。骨もモデルも同じ1つの写しの中にあるので、突き合わせが要りません。別の場面で取った2つの写しを比べたところ、ポーズは変わってもモデルは1バイトも変わりませんでした。

骨の行列は、ディスクにも実行ファイルにも入っていません。描く直前にゲームが渡すもので、動いている最中にしか存在しません。だから、動かして止めて、その瞬間のメモリを取ります。
取り方（DuckStation）
1. 設定 → 高度な設定 で「デバッグメニューを表示」をオンにする
2. ゲームを起動し、メニューバーの デバッグ → CPU デバッガ を開く
3. ツールバーの「＋」で、アドレス 8001F464・種類「実行」のブレークポイントを追加する
4. 再開して、キャラクターが画面に出ている場面まで進める。そこで止まります
5. 止まったまま、デバッグ → RAM ダンプ…（2,097,152 バイトのファイルができます）
6. そのファイルをここで選ぶ
止める番地は 8001F464 にしてください。0x8001F44C だと、その手前の分岐で「骨が無いときは素通り」するので、表が空のまま止まります。
セーブステートでも読めますが、描き終わったあとの瞬間だと表が空になっています。圧縮は Deflate か なし にしてください（既定の zstd はブラウザがほどけません）。

顔の貼りもの・手の差し替え

モデルには差し替え用の枠が入っています。8個は右手4種・左手4種で、対になるものは Z だけが符号ごと裏返り（左右の鏡像）、片側の4種は外へ届く長さが順に伸びます（握り拳→開いた手）。同時に出すものではないので、組から1つずつだけ出します。残りの1組は顔の貼りもので、面が全部テクスチャ、同じ形でパレットだけ違うものが2つ（表情違い）あります。目・眉・傷・絆創膏がここに入っています。頭の面とほぼ同じ所にあるので、少しだけ外へ押し出して描いています。
本体の腕は手首で切れていて、手はこの差し替えの部品で付きます。付く骨は、部品の頂点がいちばん重なる区切りで決めています（RAM の描く命令の並びと6つとも一致）。いまどの形を使っているかは写しからはまだ分からないので、既定は1番目です。

ファイルの中のモデル

1つのファイルに 0x90000000 のモデルが複数入っています。いちばん大きいものがキャラクター本体で、小さいものは部品の少ない簡易版のようです。

骨格の組み方

トバル2から持ってきた骨のつなぎ方で組みます。部品がばらける・重なるときは「関節を使わない」にすると、モデルの中の座標をそのまま出します。

背景

BGM

ディスクの XA から見つけたチャンネルをそのまま鳴らします。曲になっていないものも混じります。

アーカイブ

どのファイルがデータのまとまりかも自動で当てています。中身が 0% ばかりのときは変えてみてください。

解析結果

ファイル表の候補

実行ファイルの中から「位置と大きさの並び」らしいところを探しています。モデルが出てこないときは別の候補に切り替えてみてください。

ドラッグで回転 ・ 右ドラッグ／Shift＋ドラッグで移動 ・ ホイールで拡大 ・ ダブルクリックで元に戻す

ディスクイメージを読み込んでください

手元の『トバルNo.1』の .chd か .bin をここにドロップするか、下のボタンから選んでください（iPhone は「ファイル」アプリから選べます）。ディスクから取り出した実行ファイル（SLPS_004.00 など）とデータのまとまったファイルを2つ選んでも読めます。

ゲームのデータはこのページに一切含まれていません。読み込んだファイルはブラウザの中だけで読み取り、どこにも送信しません。

このビューアはトバルNo.1の中身を実行時に探しにいきます。うまく出てこないときは「解析」の内容をそのまま作者に送ってください。
